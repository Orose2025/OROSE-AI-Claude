# Agent View, le multi-agent intégré

*« Le multi-agent natif qu'on attendait depuis 2 ans »*

## Ce que c'est

Une vue intégrée à Claude Code qui permet de suivre plusieurs agents en même
temps. Le mécanisme derrière : un service qui tourne en fond et garde les
sessions vivantes.

Ce qu'il appelle le moment décisif : **fermer le terminal ne tue plus rien.**
Les agents continuent, on rattache la session plus tard. Il montre douze agents
en parallèle, un panneau pour répondre à l'un sans quitter la vue générale, et
des filtres pour s'y retrouver.

## Ce que ça vaut pour nous

À connaître, pas à installer aujourd'hui — et ce n'est pas une contradiction
avec [[Parallele-ou-sequentiel]] : Agent View permet de *voir* plusieurs agents,
il ne dit pas qu'il faut en lancer plusieurs sur le même dépôt.

Le point qui nous concernera vraiment : la session qui survit à la fermeture du
terminal. Alain travaille souvent tard, coupe, reprend. Une tâche longue qui
continue toute seule et qu'on retrouve au réveil, c'est utile.

Réserve : il précise que c'est une version d'essai, avec des limites. On attend
que ça se stabilise.
