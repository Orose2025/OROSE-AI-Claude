Comment lire le résultat

  • La barre bouge quand tu parles → ton micro, tes pilotes et les permissions du navigateur sont bons. Le problème vient alors de l'app Claude elle-même : vérifie l'autorisation micro accordée au site claude.ai (cadenas dans la barre d'adresse → Micro → Autoriser), puis recharge la page.
  • Erreur « permission refusée » → l'autorisation a été bloquée. Clique sur le cadenas dans la barre d'adresse, remets le micro sur « Autoriser », puis recharge.
  • Erreur « aucun micro trouvé » → aucun périphérique d'entrée n'est vu par le système. Rebranche le micro / le casque, ou change le périphérique d'entrée par défaut dans les réglages du système.
  • Erreur « micro déjà utilisé » → une autre application le monopolise (Zoom, Teams, Meet, Discord, OBS). Ferme-la complètement, puis relance le test.
  • La barre ne bouge pas mais aucune erreur → le navigateur écoute le mauvais périphérique. Choisis le bon micro dans les réglages du système, puis relance.
  • Autorisation impossible à donner → au niveau du système : macOS Réglages → Confidentialité et sécurité → Microphone ; Windows Paramètres → Confidentialité → Microphone. Le navigateur doit y être autorisé.
